## 3. Approach (both modes)

Principle: every rule is one shared helper that both renderers call (as `_dash_share_by_scales` is), copied into the served app by name (the helper list in `_glyph_layer_lines`, dash_render.py:~33170-33215). Chrome is drawn with canvas text (Bokeh `Title`/`Legend` in figures), never `Div`, so no new HTML sink.

**A. Parse (dash_render.py).** New `_dash_by_options(by_raw)` returns a dict: rows, cols, holes (set of ints), colfirst, title/subtitle/note/caption raw text, legend raw, clegend raw, iscale, imargin, style, edgelabel, i*axes/ticks/labels/titles, ilegends, plus the rescale set. Abbreviations transcribed from bygraph_g.class:266-283 and by_option.sthlp (`r(#)` is rows, bare `r` is rescale; `colf`, `hol`, `com`, `edge`, `iy`, `ix`, `im`). `_dash_parse_by` keeps its 5-tuple (CRITICAL, 9 direct callers) and stops naming what the new dict implements; only genuinely unimplemented words (e.g. `subtitleformat()`, `shrink`, bystyles other than default/compact/rescale/combine) stay named. `_DASH_BY_SUPPORTED` grows the new spellings.

**B. Refusals (dash.ado `_dash_validate_value`, near the by() variable check at :2341-2420)** — subject to decision D4: rows()+cols() r(198) "may not specify both rows() and cols()"; rows/cols/holes outside their ranges r(125) with twoway's text; a sub-option in capitals and a repeated `style()` r(198) "option ... not allowed". Mata reads the sub-options from the string scalar, never a macro.

**C. Panel labels.**
- `_dash_facet_label`: join `", "`; numeric `.` and string `""` give `(missing)`. Dates keep dash's display-format text (documented; D5).
- `_dash_by_groups`: a string key `""` is missing (dropped without `missing`), fixing bug d2 in both modes.
- New `_dash_by_panel_label(fig, label, graph_opts, scheme)`: the label is a second `Title` added above the figure's own title, centred, in the scheme's subheading box (fill/outline from the by-subtitle textbox); its text is `_dash_textbox_or_default(graph_opts["subtitle"], "subtitle", label)`, which already gives twoway's replace/prefix/suffix/`""` rules. Under by() `_dash_text_annotations` skips `subtitle` (consumed by the label). The em-dash joins at :31655-31656 and :35512-35520 are deleted; `fig.title` stays the graph's `title()` on every panel.
- `ring(0) pos()` on the label is P2.4's; named until then.

**D. Grid.** New `_dash_by_positions(n_panels, opts, legend_at=0)` ports set_rows_cols/set_placement exactly (full_n, `int(sqrt)+(frac>.01)`, row-major or colfirst, holes skipped, holes beyond the grid ignored, legend hole). It replaces `_dash_facet_cols` inside `_dash_layout_cell`, which builds `GridPlot(children=[(fig, r, c), ...])` (Bokeh 3.9 accepts `(model, row, col, row_span, col_span)`). cols() larger than the panels leaves empty columns up to the by_groups limit (D6; keeps TestByColsCannotOutgrowThePanels' guarantee as a cap).

**E. Chrome cells** (new `_dash_by_chrome(figs, positions, opts, scheme, var_labels)` called by `_dash_layout_cell`, so the grid, tabs, layout(bs) and both modes get it):
- Overall title/subtitle (top row, spanning), note/caption (bottom row, spanning), each a toolbar-less, axis-less figure holding a `Title`; default note `Graphs by <SetByList>` built with `_dash_var_label` (twoway's 3+-variable quirk reproduced), suppressed by `note("")`, suffix/prefix honoured.
- Outer axis titles once: a narrow left cell spanning the panel rows (`title_location="left"`) and a bottom cell spanning the columns, text = panel 1's resolved axis titles; per-panel `axis_label` cleared unless `iytitle`/`ixtitle`; axis-2 title cleared on every panel.
- Outer axes: `axis.visible=False` on inner panels by the measured rule (left column y; bottom-of-column x with edge labels; rightmost y2), overridden by i*axes/noedgelabel/compact/rescale (rescale turns individual axes on, bygraph_g.class :363-385). Prototype (proto.py, headless Chrome screenshot) showed Bokeh aligns the plot frames of a GridPlot whose inner axes are hidden.
- One legend: per-panel legends hidden unless `ilegends` or `legend(on)` outside by(); one legend-only figure whose renderers are clones of panel 1's keyed glyphs on one-row NaN sources, named with `_DASH_SWATCH_PREFIX` so filter/brush refresh skips them (`_dash_is_swatch`); items built by `_dash_apply_legend` from panel 1 (outer `legend(order/label)` contents), placed from `by(, legend(pos ring at off on))` else the scheme's `by_legend_position`/`by_legend_ring`. Prototype: swatches draw with a one-row NaN source, not with an empty one.
- colorvar: per-panel ColorBars removed; with `by(, clegend(on))` one ColorBar in a chrome cell bound to panel 1's color mapper object, so it follows panel 1 after a filter move in both modes.
- Scheme: add `clockdir by_legend_position`, `gridringstyle by_legend_ring`, `yesno by_edgelabel/by_outer_*/by_indiv_*`, `margin by_indiv` to the 20 dash-*.scheme files via scripts/extract_scheme_truth.py, read by SchemeParser.

**F. Sizes.** `iscale(#)`, `iscale(*#)` and (D2) the default f(G) multiply panel text and marker sizes (not overall text); `imargin()` and `compact` set GridPlot `spacing`.

**G. Aspect (REM-10-03, D1).** The by() array takes the graph's xsize/ysize (s01); each panel's ratio is derived from it and the grid. `_dash_auto_bs_layout._ar_of` and `_dash_auto_grid_cols` read a faceted name's cell ratio through the facet map (PHASE-22 TR-22.1, new optional `facet_map` argument threaded through `_dash_parse_bs_layout` in both callers, :30919 and the served :36291).

**H. Responsive stacking (D3).** `_dash_reflow` stacks a narrow grid into one column; spanning chrome cells must stack in reading order, and hidden inner axes would leave stacked panels unlabelled. Either a CustomJS toggle (both modes) or accept it.

**I. After a filter move.** Chrome is static text; shared ranges (P0.2) keep the outer axes right; the legend-only figure and clegend are not sources. Served: the chrome is built in `make_document` per session, from the same helpers.

**J. Docs.** dash.sthlp "Faceting with by()" (:2055-2135: remove :2091-2094, :2097, :2109-2116, :2119-2123 differences as closed; document each sub-option), CHANGELOG, BUGS.md entries for d2 and e (and per-panel sizing if D1), TWOWAY_COVERAGE_AUDIT.md:143 tag, GAPS2 B16/B26-d/B31 Tracked lines.

## 6. Decisions for the maintainer

- **D1. Whole-array size.** twoway sizes the whole by() array by xsize/ysize (s01: 8640x2160 either way); dash gives each panel the full ratio, so two panels of xsize(12) ysize(3) are 8:1.
