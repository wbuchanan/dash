## 4. dash's three scales today (the core of the Decision)

| class | dash anchor | px per rs | px per pt |
|---|---|---|---|
| text | CSS pt ("11pt") | 3.84 | 1.333 |
| marker | medium 4.4pt = 8px | 5.24 | 1.818 |
| line | .30 = 1.5px | 5.00 | 1.736 |

Stata has one: marker/text = 4.4pt/10pt = 0.44 (dash 8px/13.33px = 0.60); line/text
= .864pt/10pt (dash 1.5/13.33 = 0.1125, 30% heavier). Unifying the scales changes
every dashboard; keeping them changes only dashboards that pass explicit sizes.

## 5. Proposed approach (closes the item in both modes)

All in `dash_render.py` unless named. The three classes are copied whole into the
served app, so a staticmethod needs no copy-list edit; a module function must be
added to `_glyph_layer_lines`' name list (:33360 area).

1. `OptionTranslator.resolve_size(value, kind, default_px)` (new staticmethod),
   `kind` in {"marker", "text", "line", "gap"}; returns px (float) or raises
   ValueError for the caller's existing note path.
   - keyword: marker -> `SchemeParser._SYMBOLSIZE_PT` (zero, vtiny..ehuge);
     text and gap -> `_GSIZE_PT`, extended from ado/base/style gsize-*.style with
     tenth, quarter, third, half, full, relative*, N-pt; line -> Stata units
     (none 0, vvvthin 1e-6, vvthin .01, vthin .15, thin .2, medthin .25, medium .3,
     medthick .45, thick .8, vthick 1.4, vvthick 2.6, vvvthick 4.2).
   - bare number = rs; `#rs`, `#pt`, `#in` (72pt), `#cm` (72/2.54pt); `# unit`
     with a space reads the number as rs (twoway's reading).
   - `*#` = # x default_px (the scheme value already on the glyph/axis/title).
   - px: rs -> pt at 2.88pt/rs (4-inch reference), then per-class px/pt from
     section 4 (Decision D1 option A). Text returns pt so callers write "Npt".
   - negative: marker and text -> 0 (twoway draws nothing); gap -> kept (moves
     toward the point); line -> ValueError (dash.ado refuses first, step 4).
   - unknown name: per Decision D2 (recommended: the class's medium plus the note,
     as twoway).
   - line floor: a non-zero width below the 0.3pt SVG floor is drawn at it (D3).
2. Route every site through it:
   - markers: `_apply_marker_opts` (:8699-8704), `map_scatteri` (:13702-13706);
   - lines: `_apply_line_opts` (:8602-8606), `_apply_marker_opts` lwidth/mlwidth
     (:8731-8758), `_ci_band_style._col` (:8354-8366), `_extract_region_lwidth`
     (:5065-5085), `_dash_refline_draw` (:26346-26356), area border (:10103+);
     `translate_lwidth` becomes a thin wrapper (kind "line", default 1.5) so
     `SchemeParser._lwidth` keyword path and its 4 thin/medium calls (:6941-7004)
     stay on one table;
   - text: `_textbox_size` (:4819, all 5 callers: `_dash_figure_title`,
     `_dash_style_axis_titles`, `_dash_text_annotations`, `_dash_add_secondary_axes`,
     `_dash_apply_z_options`) gets a `default_px` from the scheme size it overrides;
     mlabsize (:9455-9460), `_dash_apply_legend` size (:21622-21629),
     `_dash_apply_axis_spec` labsize (:22837-22841);
   - gap: `_mlabel_gap_px` (:9503) -> kind "gap"; offset = marker radius
     (glyph.size/2) + gap along the clock direction; default gap = scheme
     `gsize label_gap` (half_tiny, 2pt) instead of the fixed 4px base.
   - delete `_SIZE_MAP` and the dead served global; replace `_LWIDTH_MAP` ratios (D3).
3. N1 fix in the same functions: after any marker option is applied, copy size
   (and colour/alpha/line props) to `nonselection_glyph` and `muted_glyph`, keeping
   dash's nonselection alpha (`_dash_dim_nonselection`).
4. dash.ado `_dash_validate_value` style kind (:2261-2274): read `#pt|in|cm|rs`
   and `*#`; for the line options (bounds 0,10000) refuse a negative `*#` or a unit
   value whose rs is outside 0..10000, as twoway does (r(198)). A positive `*#`
   that exceeds 10000rs only after the scheme default is applied (`*40000`) cannot
   be judged in dash.ado: the renderer notes and clamps it (documented residual).
   `_dash_option_rules` table unchanged in shape. (`dash.ado`/Mata are not in the
   GitNexus index: UNKNOWN; callers confirmed by grep: `_dash_validate_value` at
   dash.ado:2692, 2713, 5349, 5371, 7069, 7451; `_dash_option_rules` at 2580.)
5. Help (dash.sthlp): Units paragraph (:3425) states the option rule and the per-class
   anchors; mlabgap (:2159-2165) rewritten (relative units, from the marker edge,
   default 2pt); bounds paragraph (:690-701) adds units and `*#`. Fix CHANGELOG.md:522 (N2).
   ROADMAP.md:2048 closed. CHANGELOG entry noting the visual changes.
