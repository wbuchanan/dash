## 3. twoway truth (StataNow 19.5): what a fallback port would have to match

Measured by `m3.do`/`m6.do`. Each probe runs `twoway function y = <e>, range(0 2) n(5) nodraw` for the rc, and `twoway__function_gen` for the values, the fixture method. The x grid is 0, .5, 1, 1.5, 2. Records are in `m3_records.txt` and `m6_records.txt`.

**Precedence of the comparison operators, high to low:** `!=`/`~=`, `>`, `<`, `<=`, `>=`, `==`, then `&`, then `|`. All sit below `+`. Within one level they read left to right.
- `x>1!=1` gives 0,1,1,1,1. So it is `x>(1!=1)`, and `!=` binds above `>`.
- `x<0.5>0` gives 1,1,0,0,0. So it is `x<(0.5>0)`, and `>` binds above `<`. This is not left-to-right.
- `x<=1<1` gives 1,0,0,0,0, so `<` binds above `<=`.
- `x>=1<=0` gives 1,1,1,1,1, so `<=` binds above `>=`.
- `x>=1==0` gives 1,1,0,0,0, so `>=` binds above `==`.
- `x&0==0` gives 0,1,1,1,1, so `==` binds above `&`.
- `x==0|x>1&x<2` gives 1,0,0,1,0, so `&` binds above `|`.
- `1<2<3` gives 1 and `3>2>1` gives 0 (left to right).
- `1+x>2` gives 0,0,0,1,1, and `x>1*2` gives all 0.

**`!` and `~`** sit at the level of unary minus, below `^` and above `*` and `/`:
- `!x^0` gives all 0, so it is `!(x^0)`.
- `!x*0` gives all 0 and `!x/2` gives .5,0,0,0,0, so `(!x)` binds first.
- `!x+1` gives 2,1,1,1,1.
- `2^!x^2` gives 4,1,1,1,1. After `^`, the `!` takes one atom.
- `-!x` is accepted. `!-x` is r(198).
- `!!x`, `~~x`, `!~x` and `! x` are accepted.
- `=`, `&&` and `||` are r(198).

**Missing values compare as larger than every number, and `.` < `.a` < `.b`:**
- `sqrt(x-1)>0` gives 1,1,0,1,1.
- `.>x` gives 1; `x<.` gives 1; `x>=.` and `x==.` give 0.
- `.a<.` gives 0; `.b>.a` gives 1.

**Missing values in logic and in functions:**
- A missing value is true in logic: `x&.` gives 0,1,1,1,1 and `!.+x` gives x.
- `cond(c,a,b)` returns a when c is missing: `cond(sqrt(x-1),1,2)` gives 1,1,2,1,1.
- With a fourth argument, a missing c returns that argument: `cond(sqrt(x-1),1,2,3)` gives 3,3,2,1,1, and `cond(.a,1,2,3)` gives 3.
- `cond(x,1)` is r(198).
- `min` and `max` ignore missing values and are missing only when every argument is: `min(sqrt(x-1),1)` gives 1,1,0,.707,1, and `max(.a,.b)+x` is missing everywhere.
- `min(x)` is r(198).

**Rounding:**
- `round(x,y)` equals `floor(x/y+.5)*y` exactly on every probe: `round(x-1.5)` gives -1,-1,0,0,1, and `round(x,-1)` gives 0,0,1,1,2.
- `round(x,0)` gives x.
- `int` and `trunc` truncate toward zero.

**Names and `c()`:**
- Names are case-sensitive: `Ln(x)`, `MAX(x,1)` and `c(PI)` are r(133), and `_PI` is r(111).
- `normalden (x)`, with a blank, is r(111).
- `c( pi )` is accepted. `c(e)` is r(133).
- `c(N)` and `c(maxlong)` evaluate from the session (`c(N)*x` gives 0,2.5,5,7.5,10). A renderer cannot know them.

**Domains:**
- `normalden(x,0,-1)` and `normalden(x,0,0)` are missing.
- `ln(x)` is missing for x ≤ 0. `logit` is missing at 0 and 1. `invnormal` is missing at 0 and 1.

**Numeric agreement of a numpy/math port (`m5.py`, against the generator's values):**
- Exact: ln, log, invlogit (`1/(1+exp(-x))`), logit, mod (`x-y*floor(x/y)`), round (all three probes), atan.
- normalden with 1, 2 or 3 arguments: within 2.6e-16 relative.
- normal (`0.5*erfc(-x/sqrt 2)`): 8.0e-16 on [-3, 3], but 1.3e-13 in the tail (x = -35: Stata 1.1249107064724062e-268).
- lnnormal: 6.6e-15. lngamma (`math.lgamma`): 4.8e-16. asin: 2.1e-16.
- The pattern of missing values matched on every probe.
- `invnormal` needs a hand port (no scipy) and was not prototyped.

**Other Stata versions.** The file `ado/base/t/twoway__function_gen.ado` is byte-identical (`cmp`) in Stata 14, 15, 16, 17, 18.0 and StataNow 19.5. So the Stata route depends on no version-specific generator. Whether the built-in functions themselves agree in Stata 16-18 is UNCLEAR. Measuring it would mean running those console binaries (`/Applications/Stata 1x/StataMP.app/Contents/MacOS/stata-mp`), which project rules do not allow today (P1.35).

Not measurable here: Windows and Linux. They are not relevant: the Stata route runs in Stata, and the fallback is pure numpy.

## 4. Approach

### Recommended (option A): close by disposition, and make the note say why (Effort S)
1. **Disposition.** The 16 measured expressions, and every expression twoway accepts, are drawn from Stata's own points in both modes, before and after a filter move. The points-free fallback serves only specs written by hand, or registries set by hand, which dash.sthlp:511-516 says are unsupported. It stays at its ten functions, by design. Record this in BUGS.md, CHANGELOG and the DROPIN annotation.
2. **Bug fix (rule 7): the empty-layer note names neither the cause nor the remedy.**
   - New BUGS.md entry: "A function layer with no stored points that uses a function only Stata evaluates draws nothing, and the note does not say why."
   - `GlyphMapper.map_function` (dash_render.py:14854): on the fallback's `ValueError`, mark the empty renderer, as `_mark_unfit` and `_mark_silent` do. Example: `r._dash_needs_stata = "normalden"`. Take the first name the tokenizer refused; it matches `[A-Za-z_][A-Za-z0-9_]*` and is capped at 32 characters. A refusal that is not about a name sets `"expression"`.
   - `_dash_note_empty_layer` (:28349), function branch: when the mark is present, emit one note: `dash: graph 'nd' plot 1 (function) drew nothing: normalden() is evaluated only by Stata, when dash registers the graph, and this spec carries no points for it; run the graph's dash command again.` Keep the existing "drew nothing" prefix, so the tests counting `_empty_notes` still find exactly one.
   - Both modes: `_dash_note_empty_layer` and `map_function` already run in the served app (M4 shows its note). Add any new module-level helper to the served copy tuple (dash_render.py:33120-33135).
3. **Help.** Reword the fallback sentence at dash.sthlp:413-418 to give the note's remedy.
4. **Optional, Stata side.** `_dash_fn_spec_tail` (dash_parse.mata:4262) could note an empty `$dash_fpts_<name>` for a graph that has a function layer. This needs `_fp_names` to list only graphs with function layers; check dash.ado:8031-8062 first. Skip it if the renderer's note is judged enough.

### Alternative (option B): extend the fallback to Stata's data-free expression language (Effort L)
Extend `_stata_fn_parse` and `_stata_fn_eval` (dash_render.py:28693, :28877) to the grammar measured in §3:

```
or := and ('|' and)*      and := eq ('&' eq)*      eq := ge ('==' ge)*
ge := le ('>=' le)*       le := lt ('<=' lt)*      lt := gt ('<' gt)*
gt := ne ('>' ne)*        ne := sum (('!='|'~=') sum)*
sum/diff/prod/quot as today;  quot := neg ('/' neg)*
neg := '-'* bang          bang := ('!'|'~')* pow
pow := atom ('^' expo)*   expo := ('-'|'+'|'!'|'~')* atom
```

Measure `2^-!x` and `2^!-x` before fixing `expo`.

**Missing values.** Carry a missing code beside the value: 0 for a number, 1 for `.`, 2-27 for `.a`-`.z`. Arithmetic on any missing value gives `.`. A comparison compares the pair (code, value). Logic treats a missing value as true.

**Functions:**
- `cond` with 3 or 4 arguments; n-ary `min` and `max` that ignore missing values.
- `round` with 1 or 2 arguments; `int` and `trunc`.
- `ln`, `logit`, `invlogit`, `mod`, `sign`.
- `normal`, `normalden` (1, 2 or 3 arguments), `lnnormal`, `lnnormalden`, `lngamma`.
- `asin`, `acos`, `atan`.
- `c(pi)`, with blanks allowed inside the parentheses.

**Still empty, with option A's note:** `scalar()`, bare scalar names, `_b[]`, `_se[]`, variables, `runiform()` and session `c()` values.

**Tolerance.** Per function: 1e-15 relative; 1e-12 for `normal` and `lnnormal`, because of the tail measured in §3.

**Effects.** It doubles the fallback's code, and it is a second implementation of Stata's language that can disagree silently. That is the class of bug P0.6 removed.

### Alternative (option C): remove the fallback (Effort S-M)
A function layer without points draws empty with option A's note. This deletes about 270 lines from both renderers, which is less attack surface. It breaks hand-written specs that use the ten functions today, and it flips the `TestStataGrammarFallback`, `TestTheParser` and `test_every_fallback_probe` pins (rule 7: flip with a reason, never delete).
