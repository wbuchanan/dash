## Overview

**What is wrong today.**

- **ST-7.** Leaf style files on the ado-path are not read. twoway resolves any named style through findfile: with files in the working directory, `lpattern(zqpat)` (`set pattern "4 1 1 1"`) draws that pattern, `lwidth(zqw)` (`set val 2`) equals lwidth(2), `msize(zqs)` msize(5), title `size(zqg)` size(10), `fintensity(zqi)` fintensity(30), `mlabangle(zqa)`/`msangle(zqa)` 30, `plotregion(margin(zqm))` margin(9.7222 x4) -- no notes (audit ST-7, probe1 G13, p3). dash reads only `_STYLE_FILE_CLASSES = ("seriesstyle", "markerstyle", "areastyle", "linestyle", "shadestyle")` (dash_render.py:10381-10382; gate `_style_name_ok` :13063-13067), notes each leaf name and draws the default.
- **ST-15 (GW-18).** `color-*.style` and `textboxstyle-*.style` files are not read: `mcolor(mine)` with color-mine.style draws black with "named style mine not found in class color" (twoway its RGB); `tstyle(mine)`/`mlabtextstyle(mine)` draw the default (twoway the file's size and colour). Documented at dash.sthlp:6141-6153; BUGS.md "textboxstyle and color-*.style files on the ado-path are not read" (documented limit D36). test/test_help_claims_9.py::TestTheUnreadStyleFiles::test_the_reader_still_skips_both_classes pins the exact `_STYLE_FILE_CLASSES` tuple (:222-230): five classes at `090d928`, nine after WP-44 (44-02 adds tickstyle, ticksetstyle, gridstyle; 44-03 adds axisstyle), each flip carrying an R10 comment.
- **ST-10.** A shipped-name scheme file found before BASE on the ado-path (`adopath ++ <dir>` holding scheme-economist.scheme) is not used: `_resolve_path` (dash_render.py:10542-10560) returns `_shipped_path` for any of the 26 names before walking the ado-path; twoway's findfile returns the user's file (red markers on s2color's #EAF2F3, audit p3). dash.sthlp:6288-6290 says the shipped names come first "as Stata's own are in BASE", true only while BASE precedes the user's directory.
- **ST-17 (GW-18).** Scheme directives read and kept but not drawn: `clockdir p`/`p#` (default marker-label position; dash hard-codes 3, :17647-17649), the `textboxstyle` of title/subtitle/caption (read for margin/fill only, :54101, :54126), `gsize legend_col_gap`, title clocks 2-4/8-10 (`clockdir title_position 3` puts the title at the right of the plot), `yesno plabelboxed`; test/test_unread_scheme_directives.py:33-45 (W33S/W33Q lists) guards the unread set. Also "a scheme name must not be a path; files over 1 MB or linked out are skipped" (dash.sthlp:6293-6303).
- **ST-16 (GW-17).** An unknown `scheme()` is refused r(198) (dash.ado:4349-4428, the `scheme` value kind) where twoway prints "(note: scheme nosuchscheme not found, using s2color)" and draws s2color, rc 0 ([S] §5). dash.sthlp:1260-1264 and :6305-6329 call it stricter than twoway.

**After this section.** Every style class twoway reads from a file is read from one (the five, the seven leaf classes, color and textboxstyle) and feeds the reader that already draws that class; a shipped-name file placed before BASE wins as findfile's first hit; each listed scheme directive is drawn; an unknown graph-level `scheme()` prints twoway's note and draws s2color.

**Why one section.** All five items are how dash finds and reads Stata's style and scheme files.

**Test order and commit rule.** Five items, five commits, in manifest order (ST-7, ST-15, ST-10, ST-17, ST-16); each a tests task (no commit) then a fix-and-commit task. 45-03-01 writes the extract script for all five.

## Risk: [yellow] -- file reading on the ado-path, with security guards

**Why.** Reading more file classes widens what a user file can change; the scheme order touches every graph's scheme; the unknown-scheme rule changes a refusal into a note.

**Risk factors.** 1. A leaf file's value outside the reader's bounds. 2. Every file read keeps `_admit`'s containment, regular-file and size checks and the 200-line/400-byte bounds (`_STYLE_FILE_MAX_LINES` :10383). 3. test_scheme_lookup.py and test_scheme_resolution.py pin "shipped names come first". 4. Users relying on the refusal of a mistyped scheme.

**Mitigation.** 1. Each value goes through the class's existing reader, which bounds and notes it. 2. No new file-opening code: the existing `_style_file_path`/`_style_file_rows` (:13077, :13091) read the new classes. 3. Those pins are flipped with the ST-10 reason. 4. CHANGELOG "Changed behaviour" line.
