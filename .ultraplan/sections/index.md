## How to execute

0. **Before batch 1, the orchestrator creates `scripts/stata_slot.sh`** (review D6) and every section's Stata run goes through it, so at most three Stata sessions ever run at once across all worktrees (many concurrent sessions can drop `python_exec` from `~/.stata19/console/stata19.rc`):

   ```sh
   #!/bin/sh
   # scripts/stata_slot.sh <scratch-dir> <file.do>: run Stata in batch from <scratch-dir>
   # holding one of three slots, so at most three sessions run at once.
   set -u
   dir="$1"; dofile="$2"; mkdir -p "$dir/tmp"
   while :; do
     for n in 1 2 3; do
       if mkdir "/tmp/dash-stata-slot-$n.d" 2>/dev/null; then
         trap 'rmdir "/tmp/dash-stata-slot-'"$n"'.d"' EXIT
         cd "$dir" && STATATMP="$dir/tmp/" arch -arm64 /usr/local/bin/stata-mp -b do "$dofile"
         exit $?
       fi
     done
     sleep 5
   done
   ```

   (`mkdir` is atomic on macOS and needs no `flock`; a stale slot directory left by a killed run is removed by hand.)
