## How to execute

0. **Before batch 1, in the main checkout on `s3-bugs`, the orchestrator does three things.**

   0a. Creates `scripts/stata_slot.sh` (review D6) and commits it alone, mode 755, with the subject `Add the Stata slot wrapper for WP-28's parallel sections (WP-28 S00)`, before any worktree exists (worktrees are created from HEAD and must carry it). Every section's Stata run goes through it, so at most three Stata sessions ever run at once across all worktrees (many concurrent sessions can drop `python_exec` from `~/.stata19/console/stata19.rc`):

   ```sh
   #!/bin/sh
   # scripts/stata_slot.sh <scratch-dir> <file.do>: run Stata in batch from <scratch-dir>
   # holding one of three slots, so at most three sessions run at once.
   set -u
   dir="$1"; dofile="$2"; mkdir -p "$dir/tmp"
   while :; do
     for n in 1 2 3; do
       if mkdir "/tmp/dash-stata-slot-$n.d" 2>/dev/null; then
         trap 'rmdir "/tmp/dash-stata-slot-'"$n"'.d"' EXIT
         cd "$dir" && STATATMP="$dir/tmp/" arch -arm64 /usr/local/bin/stata-mp -b do "$dofile"
         exit $?
       fi
     done
     sleep 5
   done
   ```

   (`mkdir` is atomic on macOS and needs no `flock`; this text supersedes the `flock` wording of `../review/DECISIONS.md` D6; a stale slot directory left by a killed run is removed by hand.) A cscript is never handed to the wrapper directly: the runner `cd`s into `test/` first and every script opens `cscript … adodir ".."` and `do "cert_helpers.do"` relative to it, so a single script runs through a two-line driver, `printf 'cd "%s/test"\ndo "%s/test/%s"\n' "<repo>" "<repo>" "<script>.cscript" > <scratch>/run_<script>.do` then `scripts/stata_slot.sh <scratch> <scratch>/run_<script>.do` (`<repo>` is the root of the tree under test: the section's worktree `<path>/wp28-s<NN>` while the section runs there, and the main checkout `/Users/billy/Desktop/Programs/StataPrograms/d/dash` when the merger or section 19 runs); `GAPS2_ONLY=S<NN>` in that run's environment limits `test_gaps2_truth.cscript` to one section's block.
