## Risk: [yellow] -- by()'s chrome grid in both modes

**Why.** Edge titles add grid columns and rows that `_dash_by_side_grid`, `_DASH_BY_FIT_JS` and `_DASH_BY_STACK_JS` must keep in step; a misplaced cell shifts every by() graph.

**Risk factors.** 1. `_dash_by_side_grid` (:56610-56670) computes the panels' origin `p0r, p0c` from the cells present; new left/right cells change `p0c`. 2. The stacked view (`_DASH_BY_STACK_JS`) hides the outer title cells (`titles["hidden"]`); the new cells must join that list. 3. The fit hook counts rows (`nr`); new text rows inside head/foot do not change `nr`.

**Mitigation.** Grid-position unit tests for each new cell (the `(cell, r, c, rs, cs)` tuples, test_by_text.py:371-379 pattern); browser tests in both modes at 1000 and 760 px; the default by() graph's grid tuples unchanged (guard).
