## Risk: [red] -- the size of almost every figure changes

**Why.** Case 2 changes every default figure's height at desktop widths, by() graphs included; D-45-04.b changes every text, marker and line size under stcolor by 12.5%; the margin and outline add borders, a model or a wrapper to every graph.

**Risk factors.** 1. Dozens of tests pin heights, the band, font sizes and borders, by() tests among them. 2. Dashboards with many graphs grow taller. 3. The served app's literal figure lines (:70290-70307) must change with the saved constructor. 4. Accessibility and export. 5. Bokeh 3.8 vs 3.9 layout of stretch_width without bounds. 6. Layout-time callbacks that write sizes can loop (aspect -> width -> aspect) or run many times a resize (REVIEW R4-7). 7. Composites that keep build-time px outside the models the post-pass knows stay unscaled (REVIEW R4-4).

**Mitigation.** 1. 45-04-02 builds the flip list by running the files named in Evidence at the base after the change and flips each with its reason; s2color-family schemes keep factor 1, so their pins only flip for the band. 2. Documented in the help with the numbers. 3. The served literal lines are named in TR-45-04.1. 4. test_export_svg.py and the accessibility tests run in the section. 5. The Chrome tests run under both bokeh versions where available (`make test` uses 3.8 at batch end). 6. The follow is one `graph_margin` kind of 43-01's per-figure dispatcher (no CustomJS of its own), guarded by the last size and writing only on change; 41-05's by() hook gains one statement, not a second hook; a node test runs the kind's code twice at one size and asserts the second run writes nothing, and 44-02's `TestMarginResize::test_one_dispatcher` runs in the VF-4 and GW-6 tasks. 7. 43-01's post-pass additions and `fig._dash_px_args` registry and 44-02's Whisker branch and screen-unit LabelSet rule are kept as they are (no number scaled twice; the head rule goes inside 44-02's branch), the four additions of D-45-04.b are the only new rules, and a `scale(1.5)` test per composite kind (43-01's and 44-02's kinds as guards).
