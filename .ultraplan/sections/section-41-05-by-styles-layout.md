**After this section.** compact applies only without another style() and draws its black outlines; aspectratio() with shrink/overallshrink is refused in twoway's words; by(, total) without variables is r(100) "varlist required in by()"; style(combine) lays its panels in combine's regions, clock 3/9 labels and 2-4/8-10 by() titles are drawn beside, aspectratio() shapes each panel's plot region, and a smaller graph margin grows the array; every panel in a row has the same plot-region width (the shared y labels in an outer axis cell); overhangs are ignored under by() and measured on the end labels only.

**Why together.** All six are the by() grid's layout and its refusals: `_dash_layout_cell`'s by() branch, `_dash_by_spacing`, `_dash_bystyle_route`, `_DASH_BY_FIT_JS`, the array styles and the overhang helper; one owner avoids four batches touching the grid.

### Section decisions

- **D-41-05.a -- compact as a bystyle.** `_DASH_BYSTYLE_EXPAND["compact"] = (("compact",), {"subtitle": ", box astextbox blstyle(foreground)", "plotregion": "lstyle(foreground)"}, "")`; `_dash_bystyle_route` (a) drops every bare `compact` token when a `style(<s>)` with `s != "compact"` is present (style() wins), and (b) treats a bare `compact` with no style() as `style(compact)`.
- **D-41-05.b -- combine's regions.** style(combine) draws: the array inset 2.2 units from the graph's edge (CSS padding through `_dash_by_array_styles`) and each panel with its own graph-region margin (`min_border_*` = the scheme's combined graph region margin in px at the panel's size) -- the values read from the fixture's combine SVG (panel rects against the canvas); the note `"its panels are laid out on by()'s grid, not in graph combine's regions."` is removed (`_DASH_BYSTYLE_EXPAND["combine"][2] = ""`).
- **D-41-05.c -- beside placement.** A panel label at clock 2-4 or 8-10 (ring above 0) is a vertical one-colour ColorBar on the panel's `right` (2-4) or `left` (8-10), `width` = label font + the box's two margins, spanning the frame's height, its one tick at the frame's bottom (t = 0) labelled horizontally, centred on the strip; a by() title()/subtitle()/note()/caption() at clock 2-4/8-10 goes to a `dash_by_rtext`/`dash_by_ltext` cell right/left of the array (placed by `_dash_by_side_grid` outside every other side cell), vertically centred on the panels.
- **D-41-05.d -- frame aspect.** aspectratio(#) under by() sets each panel's plot region to height/width = #: `_dash_by_fit_hook(figs, ..., frame_ar=#)` drives `_DASH_BY_FIT_JS` mode "frame": per panel `p.aspect_ratio = (fw + bl + br) / (fw * # + bt + bb)` from its laid-out frame width `fw` and borders, written when it changes by more than 0.002.
- **D-41-05.e -- smaller margin.** A by() graph margin smaller than the scheme's draws a larger array: the negative excess is a negative CSS margin on the grid container (`margin: -t% -r% -b% -l%`), `overflow: visible`; this composes with 45-04 (GW-6), which later draws the scheme's base margin.
- **D-41-05.f -- outer y axis cells.** With shared y axes (no yrescale, no iyaxes/iylabels), each grid row gets a `dash_by_yaxis_<r>` cell (a bare `Plot` with one `LinearAxis` on the row's shared `y_range`, the panels' y axis style copied, no frame fill) left of column 0; every panel's own left axis is hidden, so all frames have one width. `_DASH_BY_STACK_JS` hides the cells and shows the panels' axes when stacked (the cells join `titles["hidden"]`).
- **D-41-05.g -- overhangs.** `_dash_overhangs` returns at once when the graph has a by() varlist; x takes the label of the smallest tick for the left and the largest for the right (`major_label_overrides` keys), each side raised to half its own label; without overrides the 6-character fallback stays.
