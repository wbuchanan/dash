**Measured for this section (20oct2026, scratch probe, s2color, `scatter y x, mcolor(<c>*<k>)` exported as SVG):** navy*1.5 #112F4A, *3 #091825, *10 #03070B, *20 #010406, *40 #010203, *50 #010102, *51 #010102, *52 #010304, *53 #010304, *60 #010304, *100 #010304, *1000 #010304; red*50 #050000, *60 #040000, *100 #030000, *1000 #010000; gs8*50 #030303, *51 #030303, *52 #020202, *100 #010101, *1000 #010101. The rule these fit exactly: for an intensity k > 1, let m be the smallest non-zero channel of the colour; when m / k <= 0.5 the intensity used is m instead of k; each channel is c / k_used rounded half up. (navy = 26 71 111: at *52, 26/52 = 0.5, so k_used = 26 and the colour is 1 3 4.) `translator query gph2svg` on this machine returns `r(fontface)` "Helvetica", `r(fontfacesans)` "Helvetica", `r(fontfaceserif)` "Times", `r(fontfacemono)` "Courier", `r(fontfacesymbol)` "Symbol".

**After this section.** dash's colour intensity follows twoway's rule at every k (the extract script re-measures a grid of colours and intensities); a blank style-list element is refused with twoway's line first (dash's hint may follow as a second line, M12); the svg translator's plain-text `fontface` is read the way the three tag faces are and leads the family of every unmarked text when it is not Helvetica (Stata's default, which Bokeh already draws). ## Risk: [yellow] -- every colour and every text font pass through these readers

**Why.** `stata_colour` reaches every colour option and scheme colour; the default face reaches every text model in both modes.

**Risk factors.** 1. The intensity change could move colours other tests pin (any `*k` with k >= 2m). 2. The font family on every text model changes the saved page's model (parity, size snapshots). 3. Fonts in exported SVG.

**Mitigation.** 1. colour_grammar_truth.json's 125 rows and the new grid are the pins; anything else that moves is a flip with reason. 2. When `r(fontface)` is "Helvetica" (Stata's default) no `"plain"` key exists and no model changes (D-45-05.c); a guard test asserts the default page's models are unchanged; parity entries compare both modes for an injected face. 3. test_export_svg.py runs.
