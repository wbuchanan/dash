## Risk: [red] -- every legend's keys; a JS-painted key; a composite legend layout

**Why.** Every legend with a marker key changes (size and width), every merge decision changes rule, and two new pieces of layout-time and paint-time code draw keys.

**Risk factors.** 1. Many pins on key counts and merged texts (test_legend_histogram_only.py, test_legend_order.py, test_series_labels.py). 2. CSP and the `defs` module code. 3. SVG export of the cell (README corpus). 6. An emptied layer's painted key must disappear after a move, per panel view. 7. The stale cue must still find a painted item.

**Mitigation.** 1. The fixture's merge cases decide; flips carry reasons. 2. 43-04-02's spike and test_csp_browser.py. 3. 42-02's name `__dash_keyproxy` and tag `dash_key_proxy` (the parity and coverage counters already skip that name, 42-02); tests assert their absence from every HoverTool and DataRange1d and that each proxy's source and view filter are its real renderer's. 4. A MOVE_CORPUS case and a Chrome stale-suffix check per painted shape family, both modes.
