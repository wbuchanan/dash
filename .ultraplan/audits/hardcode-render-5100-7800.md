## Adjacent bugs found while auditing (not hardcoded-value findings)

1. **Double HTML-escape in the Bootstrap path.** `render()` escapes at `:7517-7518`
   (`title_text = html.escape(...)`), then `_render_bootstrap_html` escapes again at `:6551` / `:6555`.
   A title containing `&` renders as `&amp;`. The gridplot path (`:7459`, `:7467`) escapes once and is correct.
2. **Faceted graphs disappear under `layout(bs)`.** `_render_bootstrap_html` collects grid items with
   `elif name in self.figures` (`:6546`), but a `by()` graph is keyed `name__by__0..N` in `self.figures`
   and only the bare `name` is in `all_names`. The gridplot path handles this via `self._facet_map`
   (`:7398-7431`); the Bootstrap path does not, so the graph is silently omitted.
3. `"_linked_graph_views" in dir()` (`:7692`) — relies on no-arg `dir()` returning local names; correct
   today but fragile. An explicit `_linked_graph_views: dict = {}` before the `if link_names:` branch is safer.
