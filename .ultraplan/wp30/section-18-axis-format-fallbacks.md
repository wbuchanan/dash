## Overview

**What is wrong today.** DROPIN-REMAINING.md:88-95 (P1.5): "Default ticks ignore the variable's display format: weight %9.0fc gives 2000, not 2,000. %g/%gc formats are never used as the fallback. `xlabel(, format(%td…))` is silently ignored. A numeric `format()` on a date axis writes epoch ms. The help's log example promises commas that dash does not write." GAPS2 G10 (GAPS2.md:1452-1457) measured the same: "`%9.0fc`, `%9.2f` and `%8.0gc` with no `ylabel()` all got BasicTickFormatter, and `%8.0gc` never gets a pattern."

Re-measured at `c96facd` in both modes (research p1-05 §1, Evidence E3), dash writes:
- `dash scatter mpg weight` (weight `%8.0gc`): Bokeh's `2000 3000`; twoway writes `2,000 3,000 4,000 5,000`.
- `ylabel(#5)` on price: Bokeh's text; twoway writes `0 5,000 10,000 15,000`.
- `dash line close date, xlabel(, format(%9.0fc))`: `9.47e+11` (epoch milliseconds); twoway writes `14,976 15,066 …`.
- `xlabel(, format(%tdDD/NN/CCYY))`: the picture is dropped without a word; twoway writes `01/01/2001`.
- `scatter mpg weight, xlabel(, format(%td))`: Bokeh's numbers, no note; twoway writes `23jun1965 19mar1968 …`.
- `format(bogus)`: a note and unformatted ticks; twoway refuses it, r(198).
- A second axis with no `ylabel2()`: Bokeh's text; twoway writes its first layer's format (`5,000`).
- `xvarformat()`/`yvarformat()`: "ignoring unsupported option(s)"; twoway reads them.

Measuring this file also found a wider writer defect, P1.5.7 (Evidence E5). Against 3,234 `display` rows of narrow explicit-digit formats, dash's writer differs on 457 of 1,100 `%g` rows, 440 of 1,100 `%e` rows and 46 of 1,034 `%f` rows. For example, `%6.4g` of .0001 is `1.0e-04` (dash `.0001`), `%6.2e` of 12345 is `1.2e+04` (dash `1.e+04`) and `%10.1g` of 1.23 is `1.2` (dash `1`). A histogram's y axis is `%6.4g` in twoway, so P1.5 cannot be right without this fix. The same writer serves KPI `fmt()`, `mlabformat()`, tooltips and slider values.

### E4 — twoway's rule (research p1-05 §2.3-2.4; StataNow 19.5, stcolor, SVG)

An axis takes `plotregion.dimformat`, the format of its first view's serset column in that dimension (axis.class:260-273, plotregion.class:549-573, yxview.class:244-258). A computed layer's serset holds generated variables with their own formats (twoway_histogram_parse.class:135 `format %6.4g`).

|---|---|---|---|

| rarea, rbar, rspike, rcap, rcapsym, rline, rconnected, rscatter, tsrline | x var's | **yvar1**'s | `rarea price mpg weight`: y `5,000`; `rarea mpg price weight`: y `5000` (u12, u13) |

## Technical requirements

- **TR-18.1 Scientific decimals (P1.5.7).** In `_dash_sci_decimals` (20380) and its twin `dash_fmt_sci_decimals` (17669):

  - `g`'s cap is `max(dec, 2) - 1`;

- **TR-18.2 Explicit-digit `%g` (P1.5.7).** In `_dash_g_text` and `dash_fmt_g_text`, the `dec > 0` path follows Stata's measured rule. `dec == 0` is unchanged. `P = max(dec, 2)`, the effective width `we = max(width, 4)` and `pu = we - 2`.
  - (a) **a ≥ 1** (`I = exp + 1` integer digits):
    - If `I > pu`, write scientific with `_dash_sci_decimals(width, ed, dec, sig_digits=True)`.
    - Otherwise `decimals = min(max(P, I) - I, pu - I)`; round half away from zero.
    - If the rounding carries to `I2` digits and `I2 > max(P, I)` or `I2 > pu`, write scientific with the floor's decimals (1 for a two-digit exponent, 0 for three).
    - Else write fixed, with trailing zeros and a bare point stripped.
  - (b) **0 < a < 1**: `lz = -exp - 1` and `fs = min(P, pu - lz)`.
    - Write scientific when `exp < -5` or `fs < 1 + _dash_sci_decimals(width, ed, dec, sig_digits=True)`.
    - Otherwise round to `lz + fs` decimals, strip trailing zeros, and drop the leading `0`.
  - (c) **Zero** writes `0` (not `0.0e+00`, which is the auto form's).

### Traps for the executor

- **A date axis is not a numeric axis.**
  - `_dash_apply_axis_options` applies the helper's answer on a date axis only when it came from `xvarformat()`/`yvarformat()` (`by_option`). Otherwise the date writer set at figure creation (30316-30322; template 35194-35199) stays.
  - The helper returns `""` for a date variable, so a mixed date/numeric axis keeps today's text: that is S35's.
  - Without this, an `lfit` first layer on a date x would write `%9.0g` day numbers and break the ratified divergence (`TestAUnivariateDateIsOnX`).
- **The explicit-digit `%g` rule has three parts that look odd but are measured.**
  - `d` 1 and 2 behave alike (`P = max(d, 2)`).
  - The threshold below 1 is `exp < -5`, not C's `-4`: `%12.2g` of .00001 is `.00001`, but of .0000029394 `2.9e-06`.
  - A rounding carry goes scientific with one decimal: `%12.3g` of 999.96 is `1.0e+03`, not `1.00e+03`.
  - Widths below 4 behave as 4.
  - Do not "simplify" any of them. The 5,700 `narrow_formats` rows are the judge, and the prototype matched every one of the 1,050 non-zero grid rows.
- **Exact binary rounding.** 0.000012345 is below its decimal spelling in binary, so `%10.4g` writes `.00001234`. Use `_dash_stata_round` on the exact value, never `Decimal(repr(a))`.
- **Keep the labels-only formatter byte for byte** when no format and no writer applies (a direct `_dash_apply_axis_spec` call). `test_adversarial_matrix.py::TestAxisLabelInjection` asserts its exact code. Every production call now passes a fallback, so the labels-plus-format formatter is the one users get.
- **One note per render, not per panel.** Use `_dash_warn_once` with a key holding the option and the format (cut to 80 characters). `_dash_reset_notes` clears it per render; a by() graph must print one note.
- **S10's spellings.** `_dash_axis_fmts` reads only lower-case names of 3 to 6 letters that prefix `format`. `fo()`, `f()`, `FORMAT()` and duplicates in one copy are S10's refusals (Evidence E6) and must not be refused twice or in other words.
- **The after-comma refusal is free.** `_dash_refuse_foreign` refuses a word the plot parser takes alone. Declaring `XVARFormat()` is the whole of BR-18.7; do not add a rule.
- **Served notes.** In batch 6 a note raised inside the served `make_document` reaches the test's warning capture, not the Stata console; S23 (batch 8) relays it. Tests count notes in both modes through `Built.warnings`.
- **python_exec hazard.** Many concurrent Stata sessions can drop `python_exec` from `~/.stata19/console/stata19.rc`, and then the truth script exits 222. A SKIP is not a pass: check the file after each driver run.
- **The hook.** A Bash command whose text names the cscript runner file or `pytest test/` counts as a full-suite launch (`.claude/hooks/guard-full-suite.sh`). Write files with the editor, and run only the file lists the tasks give.
