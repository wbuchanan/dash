## 2. Code at HEAD

All three families are read by shared module functions that the served app copies by source (`ServerAppBuilder._glyph_layer_lines` copy lists, dash_render.py:32931-32944 constants, :33220-33221 legend, :33229-33230 axis, :33370-33382 refline/textbox), so one fix covers both modes.

- Legend: `_DASH_LEGEND_SUBOPTS` (dash_render.py:25823-25825) holds exact names only (`pos` is the only short form). `_dash_legend_parts` (:21252) lower-cases each name and keeps it as typed; `_dash_legend_arg` (:21276) returns the FIRST match; `_dash_apply_legend` reads `("position","pos")` :21550, `ring` :21551, `cols`/`rows` :21604-21605, `size` :21621, words `on`/`off` :21637-21638, `label`/`order`/`lastlabel` by exact name :21483-21516. `_dash_legend_unsupported` :25834 names everything else.
- Axis labels: `_dash_parse_axis_spec` (:22602) accepts by exact name only `format`, `labsize`, `angle`, `grid`, `nogrid` (:22647), plus `val…` up to `valuelabel` (:22639) and `norescale`; the VALUES are read by regex over the WHOLE raw text, quoted labels included: `\bformat\s*\(` :22650, `\blabsize\s*\(` :22653, `\bnogrid\b`/`\bgrid\b` :22656-22659, and `_parse_axis_angle` (:4998, regex `\bangle\s*\(`) :22649. Callers: xlabel/ylabel (`_dash_apply_axis_options` :23019), xtick/ytick (`_dash_apply_tick_option` :22904, which re-names format/labsize/angle by exact name :22909), ylabel2/xlabel2 (`_dash_finish_secondary_axes` :23236), zlabel (`_dash_apply_z_options` :26149, which re-names honoured values as `labsize(<value>)`, not as typed).
- xline/yline: `_DASH_REFLINE_SUBOPTS = {lcolor, lpattern, lwidth}` (:26221); `_dash_refline_instances` (:26290-26291) matches exact names and slices the argument by `len(name)`.
- Stata side: `_dash_rep_subkey` (dash_parse.mata:5632-5652) keys repeated legend/axis/title sub-options for the merge of repeated options: exact lower-case name, `noX`→`X`, `pos`→`position`, `cols|rows` as one, `label #`/`lastlabel #` keyed by number only when spelled in full.

## 5. Approach (closes both modes; build-time only, so a filter move cannot change it)

1. **One canonicaliser, three tables (dash_render.py).** Add `_dash_subopt_canon(name, table)`: the first `(full, minimum)` in *table*, in twoway's parse order, with `len(name) >= len(minimum)` and `full.startswith(name)`; else `None`. Order is the rule that makes `c`→cols (not color), `la`→lalign (not label), `s`→size. Tables transcribed from the three parsers above, each row cited:
   - `_DASH_LEGEND_SUBOPT_TABLE` (position/pos, ring, style/sty, order, span, rows/r, cols/c, colfirst/colf, … ON, OFF, the textbox rows with size/s, color/c, lalign/la …, label/lab, lastlabel/lastlab, region/reg).
   - `_DASH_AXLABEL_SUBOPT_TABLE` (add, custom, norescale, notick(s), tick(s), nolab(els), labels, noval(uelabels), val(uelabels), ang(le), alt(ernate), sty(le), tsty(le), tl(ength), tp(osition), labgap, labsty(le), labs(ize), labc(olor), nog(rid), g(rid), gs(tyle), gex(tend), gls/glw/glc/glp, for(mat), ax(is), …).
   - `_DASH_REFLINE_SUBOPT_TABLE` (st(yle), noex(tend), ex(tend), lst(yle), lc(olor), lw(idth), lp(attern), la(lign), ax(is)).
   Keep `_DASH_LEGEND_SUBOPTS`/`_DASH_REFLINE_SUBOPTS` as the honoured FULL names; add `valuelabels`. Case: per decision D1 (recommended: lower case only, as twoway; `_dash_axis_words` :2861 already treats capitals as refused).
2. **Legend.** `_dash_legend_parts` returns canonical names (typed token kept for the note); `_dash_legend_unsupported` tests the canonical name; `_dash_legend_arg` returns the LAST match (twoway: last copy wins; within one copy twoway refuses, D2); `_dash_apply_legend` drops the `"pos"` alias and, when both `rows()` and `cols()` are present, applies rows and sets `ncols="auto"` (N7).
3. **Mata merge (dash_parse.mata `_dash_rep_subkey`).** For category "I" (legend) canonicalise the name before keying: `lab…`/`lastlab…` → `label #`/`lastlabel #`, `c/co/col/cols` → `cols`, `r/ro/row/rows` → `rows` (separate keys; the renderer applies rows-wins), `pos…` → `position`, `s/si/siz/size` → `size`. A twin of the legend table's honoured rows only; a cscript case asserts the twin against the Python table so they cannot drift. Axis "L" needs no Mata change (the renderer's last-wins handles `labs(large) labsize(small)`).
4. **Axis labels.** `_dash_parse_axis_spec` reads every sub-option from the tail tokens only (`_dash_axis_head_split` + `_dash_by_tokens`), canonicalised, last occurrence per setting wins (grid/nogrid one setting; valuelabels/novaluelabels one setting); values come from the token's argument, so quoted label text is never read (closes N4 and P2.20's REM-09-02-SUBOPT-IN-LABEL). `_parse_axis_angle` gets the argument (or `angle(arg)`) instead of the whole text. Spec keys unchanged; add `typed` so `_dash_apply_z_options` names `labs(large)` as typed. `_dash_apply_tick_option` compares canonical names. `glc`/`labc`/`tl`… become canonical but stay named until P1.18/P2.20 honour them.
5. **xline/yline.** `_dash_refline_instances` canonicalises with the refline table and takes the argument from `tok.split("(", 1)[1]`, not `len(name)`. Unchanged: numlists (P1.21), lstyle/noextend/lalign (P1.21, named).
6. **Textbox table (N5).** Correct `_TEXTBOX_SUBOPTS` minimums from `_fr_tbstyle_parse_and_log.ado`: size `s`, alignment `a`, lstyle `lst`, nobox `nob`; add angle (exact) and the bf*/bl* rows. Visible change: `s()` is honoured; `ls()` (refused by twoway) is named instead of being read as lstyle (still named either way).
7. **Served app.** Add each new table and `_dash_subopt_canon` to the copy lists in `ServerAppBuilder._glyph_layer_lines` (dash_render.py:32931-32944 and :33370-33382); `test_resource_limits.test_no_function_in_the_app_reads_an_undefined_global` catches a miss.
8. **Docs.** dash.sthlp: the sub-option paragraph (:615-627), legend paragraph (:2785-2808), axis labels (:2810+), ylabel2 paragraph (:3018-3027), xline text; list the spellings with `{cmd:}` (not `{cmdab:}`, which `test_abbreviations.py::test_help_documents_only_accepted_abbreviations` checks against top-level option tables).
